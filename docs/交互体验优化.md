# 交互体验优化

> 记录基于真实使用反馈的 CLI 交互体验改进。

---

## 问题与改进

### 1. SubAgent 状态展示

**问题**：用户无法知道 Agent 是否在使用子代理工作。

**改进**：在 `query.py` 中，当 `agent` 工具被调用时，显示 SubAgent 的创建和完成状态：

```
  ┌─ SubAgent [explore] (sync): search TODOs
  [sub] grep_search: main.py:1:# TODO...
  └─ done

  ┌─ Teammate [general]: researcher
  └─ done

  ✓ Agent [explore] completed     ← 异步 Agent 完成通知
```

### 2. 权限确认展示操作详情

**问题**：确认提示只显示工具名（如 `⚠ Requires confirmation: run_shell`），用户无法判断是否安全。

**改进**：显示具体操作内容：

```
# 之前
  ⚠ Requires confirmation: run_shell
  Allow? (y/n):

# 之后
  ⚠ Shell command: rm -rf /tmp/old_builds
  Allow? (y/n):

  ⚠ Write file: src/main.py (2048 bytes)
  Allow? (y/n):

  ⚠ Edit file: config.yaml (replace: "port: 3000...")
  Allow? (y/n):

  ⚠ Launch sub-agent: [explore] search code patterns
  Allow? (y/n):
```

**实现**：`_format_permission_detail()` 函数根据工具类型生成不同的详情描述。

### 3. 等待动画（Spinner）

**问题**：LLM 响应前（特别是免费模型限速时），界面完全静止，用户不知道 Agent 是否在工作。

**改进**：添加 `_Spinner` 类，在 LLM 调用期间显示旋转动画：

```
⠹ thinking...     ← 等待 LLM 响应时的旋转动画
```

收到第一个流式 token 后自动停止动画，切换为逐字输出。

**实现**：后台守护线程循环打印 Unicode Braille 字符（⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏），100ms 间隔。

### 4. 多行输入

**问题**：`input()` 只读取一行，粘贴多行文本时后面的行丢失。

**改进**：

**方式 A：自动检测多行粘贴**

粘贴多行时，`select.select()` 检测 stdin 有缓冲数据 → 进入多行模式（空行结束）：

```
coding-agent >> 第一行被粘贴
  (multi-line mode: empty line to submit)
  ... 第二行
  ... 第三行
  ...                    ← 空行提交
```

**方式 B：`/edit` 命令打开编辑器**

```
coding-agent >> /edit
  → 打开 $EDITOR（默认 nano）
  → 用户在编辑器中编写多行 prompt
  → 保存退出 → 提交
  (submitted 256 chars)
```

**技术说明**：
- `select.select([sys.stdin], [], [], 0.05)` 检测粘贴缓冲（50ms 超时）
- `/edit` 使用 `$EDITOR` 环境变量或 fallback 到 `nano`
- Windows 不支持 `select.select` 在 stdin 上，但 `/edit` 仍可用

## 修改的文件

| 文件 | 改动 |
|------|------|
| `query.py` | Spinner 等待动画、权限详情展示、SubAgent 状态标记、异步通知展示 |
| `screens/repl.py` | 多行输入（自动检测 + /edit 编辑器）、Tips 提示 |

## 配色方案

| 颜色 | 用途 |
|------|------|
| \033[36m 青色 | 输入提示 `coding-agent >>` |
| \033[35m 紫色 | SubAgent / Team 状态 |
| \033[32m 绿色 | 工具执行成功 |
| \033[31m 红色 | 权限拒绝 |
| \033[93m 黄色 | 权限确认详情 |
| \033[90m 灰色 | Spinner、多行模式提示、Tips |
| \033[33m 橙色 | 上下文警告 |
